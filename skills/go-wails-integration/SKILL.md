# Skill: Связь Go и настольного интерфейса

## Когда применять

Организовать обмен между вычислительным ядром Go и приложением Three.js/TypeScript через Wails.

## Входы

Схемы данных, методы mass-engine, события UI и жизненный цикл окна.

## Рабочий процесс

1. Зафиксировать контракты сериализации и версионирование проекта.
2. Продумать реактивное обновление сцены после изменения параметров.
3. Определить операции чтения/записи JSON, экспорта PNG/CSV и обработки ошибок.
4. Сделать проверку окружений WebGL/WebView на Windows/Linux/macOS.

## Выходные артефакты

API-контракты, схемы данных, план окружения сборки, матрица поддержки ОС.

## Условия приёмки

- [ ] Go — единственный владелец бизнес-логики масс.
- [ ] Все ошибки пересчётов видны пользователю и логируются.
- [ ] Сохранение/загрузка не теряет seed, источники и фильтры.
- [ ] Работа без сети доступна для демо-пресетов.

## Непереговорные ограничения

Работать в рамках `TECHNICAL_SPECIFICATION.md`. Не выдавать синтетические данные за наблюдения. Не допускать двойного счёта массы. В явном виде фиксировать единицы, источники и принятые допущения.

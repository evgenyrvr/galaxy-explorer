# Skill: UI: дерево, инспектор и редактор

## Когда применять

Спроектировать понятные средства выбора и управления составом галактики.

## Входы

Структуры и данные массы, макет экрана, события рендерера.

## Рабочий процесс

1. Сформировать дерево галочек с тремя состояниями и поиском.
2. Спроектировать клики по объектам, Ctrl/Shift-выбор, «изолировать», возврат вида.
3. Разделить «видимое», «выделенное», «считать массу».
4. Сделать редактор M_total, процентных долей, блокировки и Undo/Redo.
5. Добавить графики с верными единицами и отметкой происхождения данных.

## Выходные артефакты

Пользовательские сценарии, состояния UI, UX-макеты, контракт событий.

## Условия приёмки

- [ ] Выделение тонкого диска даёт только его массу.
- [ ] Сумма долей всегда видима; ошибка 100% объяснима.
- [ ] Видимая прозрачность не влияет на физические массы.
- [ ] При импорте Σ(R) интерфейс не маркирует ось как ρ(r).

## Непереговорные ограничения

Работать в рамках `TECHNICAL_SPECIFICATION.md`. Не выдавать синтетические данные за наблюдения. Не допускать двойного счёта массы. В явном виде фиксировать единицы, источники и принятые допущения.
